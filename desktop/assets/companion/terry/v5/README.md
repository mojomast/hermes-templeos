# Terry HD loops (fan tribute)

An original fan tribute with no official TempleOS affiliation. Six silent 720×1080 transparent VP9 loops at 20 fps, shipped as `exports/*.webm` only (idle, walk, speaking, wave, typing, smoking).

During typing, the cigarette rests in an ashtray on the desk; the smoking loop retains the cigarette attached to the hand. VP9 alpha support varies by player — if it cannot play, keep the previous v4 rig as a fallback.
